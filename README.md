# 月满中秋 · 花好月圆

一个中秋主题的互动网站，传统国风视觉（深蓝夜空 + 暖金色调），集**祝福贺卡生成、猜灯谜、中秋图集**三大功能于一体，辅以背景音乐与夜空动画，营造团圆温馨的节日氛围。纯前端实现，双击即可运行。

> 线上地址：https://e45a2f4947634051a116603b6c812e46.app.workbuddy.host

---

## 站点内容

网站共五个页面，首页为导航入口，其余四页分别承载不同的互动体验。

### 首页

- 一轮浮动明月缓缓升起，配以标题「月满中秋」与诗句「但愿人长久，千里共婵娟」。
- 三张入口卡片，一键进入祝福贺卡、猜灯谜、中秋图集。

### 祝福贺卡（核心功能）

自由创作一张专属中秋贺卡：

- **画布规格**：支持 3:4 竖版与 4:3 横版两种比例，导出为 2 倍清晰度的 PNG。
- **可添加元素**：月亮、玉兔、孔明灯、桂枝、月饼、文本框，均可重复添加。
- **默认排版**：满天星、远山、圆月、标题、祝福语、落款，开局即是一张完整贺卡。
- **自由编辑**：点击选中、拖拽移动；拖四角缩放与旋转（文字元素仅缩放）；拖四条边调整宽高；右键镜像或删除。
- **文字输入**：标题、祝福语、落款三个输入框与画布双向同步，可单独调节字号；内置 8 条常用祝福语，一键选用。
- **一键成片**：点「生成 PNG 贺卡」导出高清图片，随时分享给亲友。

### 猜灯谜

- 收录 15 条经典灯谜，涵盖字谜、成语、动物、自然物、地名等。
- 提示直接拼在谜面后括号内，如「十五天（打一字）」。
- 提供「上一题 / 看答案 / 下一题」导航，答错即断连对。
- 实时统计：已答题、答对、正确率、当前连对、最佳连对、攻克进度。
- 「清空成绩重来」一键归零；成绩仅在本次浏览期间有效。

### 中秋图集

- 8 个中秋意象卡片：满月、玉兔、花灯、桂花、月饼、嫦娥、团圆、灯谜。
- 每张配一段诗意文案，讲述意象背后的节日故事与习俗。

### 作者信息

- 项目介绍、作者联系方式，以及一枚动画风格的月饼图案。

## 全站体验

- **夜空动画**：闪烁的星星、缓缓升起的孔明灯、飘落的桂花花瓣，贯穿每个页面。
- **背景音乐**：默认自动播放，点按钮即可停止，再点继续；切换页面时进度续播。
- **响应式设计**：手机与桌面均可流畅浏览。

## 快速开始

无需安装任何依赖，直接双击 `index.html` 即可在浏览器中打开，完整使用全部功能。

> 若浏览器在本地文件协议下遇到异常，可起一个本地静态服务：
>
> ```bash
> # 在项目根目录执行
> python -m http.server 8000
> # 然后访问 http://localhost:8000/
> ```
